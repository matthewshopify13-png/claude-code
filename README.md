# HerBloom — Landing Page

A static homepage recreation for **HerBloom**, the women's wellness / anti-cellulite
legging brand ("Stop hiding your legs" · LYMPH3D™ technology).

## Files
- `index.html` — homepage markup
- `styles.css` — theme (warm cream, deep pine green, terracotta accents; Playfair Display + Jost)
- `script.js` — mobile menu, add-to-cart counter, newsletter form

## Preview
Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Notes
Built to closely match the live store layout (announcement bar, centered logo nav,
trust bar, hero with product card, bestsellers grid, "Wrong Problem" section,
how-it-works, reviews, guarantee CTA, and footer). Product photography is
represented with CSS placeholders — swap in real HerBloom imagery to finish.
